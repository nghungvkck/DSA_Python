📖 Giới thiệu
Repo này được xây dựng với mục đích tìm hiểu và khám phá từ những nguyên lý cơ bản nhất. Đây là nơi lưu trữ các thuật toán được triển khai hoàn toàn từ đầu (from scratch)  chỉ sử dụng các thư viện cơ bản.

💡 "Hiểu sâu để làm chủ" - Mỗi thuật toán đều được code thủ công để hiểu rõ cơ chế hoạt động bên trong, thay vì chỉ gọi API từ các framework có sẵn.

🎯 Mục đích
Học tập và nghiên cứu: Hiểu sâu về toán học và thuật toán đằng sau các mô hình thuật toán

Tài liệu tham khảo: Code sưu tầm và tự viết để dùng cho các dự án sau này

Thực hành: Áp dụng kiến thức vào các bài toán thực tế

Chia sẻ: Cộng đồng có thể tham khảo, đóng góp và phát triển
